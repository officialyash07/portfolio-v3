A modern, fast, and responsive **developer portfolio website** built with **React and Vite**.  
This is the **third iteration** of my personal portfolio, designed to clearly showcase my **projects, skills, and frontend expertise** using modern tooling and clean UI practices.

## 🎯 Purpose

This portfolio is built to:

- Present real-world frontend skills
- Showcase personal and academic projects
- Demonstrate clean React architecture
- Serve as a professional profile for recruiters and collaborators

---

## 💻 Tech Stack

- **React** – Component-based UI
- **React Router** – Navigation
- **Vite** – Fast build and development tooling
- **JavaScript (ES6+)**
- **CSS / Tailwind CSS**
- **npm**
- **ESLint**

---

## ✨ Key Features

- Fully responsive (mobile, tablet, desktop)
- Fast loading and optimized build
- Clean and modern UI
- Scalable component structure
- Easy content customization
- SEO-friendly layout
- Production-ready setup
